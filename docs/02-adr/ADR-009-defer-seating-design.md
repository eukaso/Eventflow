# ADR-009 — Defer Seating Implementation Until Venue Constraints Are Known

**Status:** Accepted  
**Date:** 2026-08-06  
**Category:** Product / Architecture

## Context

A useful seating planner depends on actual table count, capacities, room layout, and grouping constraints.

## Decision

The seating module remains architecturally anticipated but implementation is deferred until venue/table constraints are confirmed.
