# ADR-007 — Submitted Companions Become Attendees

**Status:** Accepted  
**Date:** 2026-08-06  
**Category:** Data Model

## Decision

Once a companion name is submitted, the system shall create or maintain an individual attendee record associated with the invitation rather than treating the companion only as a JSON/text value.

## Rationale

Individual attendee records enable seating, place cards, reception search, check-in, reporting, and future attendee-level attributes.
