# EventFlow 1.1.0 — Sprint 10 API Completion

- **Status:** Release candidate — CI pending
- **Target release tag:** `v1.1.0-api-completion`
- **Candidate date:** 2026-08-20
- **Input release:** `v1.0.0-delivery-adapters`

## Scope

EventFlow 1.1.0 completes the designed Event-management API surface backed by authoritative application contracts. It extends the Sprint 9 command adapters with bounded read models, revision-safe lifecycle operations, hardened administration, protected artifact delivery, privacy administration, audit review, and sanitized diagnostics.

## Included

- Event list/detail and revision-guarded draft updates;
- Venue and Event-configuration resources;
- least-privilege Membership, Invitation, and Attendee reads;
- guest-safe Invitation context, RSVP reads, and exact-session logout;
- complete Seating resource management, durable recommendations, and atomic group moves;
- complete Template and Campaign administration plus Message review and logical retry;
- hardened multipart Import staging and administration;
- protected Export creation, status, detail, and integrity-verified download;
- Privacy Action and retention-hold administration;
- minimized audit-history list/detail and pinned-chain integrity inspection;
- privileged sanitized diagnostics without raw-log access;
- executable IMP-046–IMP-077 traceability and catalogue reconciliation.

## Compatibility

- Minimum PHP: 8.2
- Minimum WordPress: 6.5
- EventFlow schema: 15
- Schema versions 7 through 15 are forward-only controlled extensions.
- Ordinary HTTP bootstrap remains read-only and never executes migrations.
- Existing Sprint 3–9 baselines remain frozen and are not rewritten by this release.

## Controlled deferral

Migration status and Migration readiness endpoints remain deferred until an authorized, sanitized query service exists. No placeholder route is included.

The bundled Provider registry remains deployment-configured. Live WordPress/MySQL acceptance, provider certification, deployment secrets, and any product UI are outside this repository-local candidate gate.
