# EventFlow 0.8.0 — Sprint 7 Implementation Foundation

- **Status:** Released
- **Release tag:** `v0.8.0-foundation`
- **Date:** 2026-08-16
- **Input baseline:** `v0.7.0-services`

## Scope

EventFlow 0.8.0 is the first controlled implementation foundation derived from the approved architecture, database, API, security, and application-service baselines. It introduces the WordPress plugin bootstrap and the shared infrastructure required by later authoritative domain services.

## Included

- immutable configuration and runtime/schema compatibility gates;
- controlled forward-only migration framework and schema versions 1–4;
- WordPress database adapter, table registry, and repository infrastructure;
- explicit transaction manager with nested transaction policy;
- typed principals, current-state Event authorization, and break-glass recovery port;
- scoped idempotency with leases and return-once result protection;
- append-only tamper-evident audit infrastructure;
- durable typed background jobs, leases, reconciliation, and worker schema gate;
- authoritative API error catalogue and sanitized translation;
- distinct health/readiness reporting with core and optional dependency semantics;
- deterministic PHPUnit harness and PHP 8.2/8.3 CI matrix;
- integrated typed foundation composition and architectural invariant validation.

## Compatibility

- Minimum PHP: 8.2
- Minimum WordPress: 6.5
- EventFlow schema: 4
- Ordinary HTTP bootstrap remains read-only and never runs migrations.
- Databases behind the application require an explicit controlled migration.
- Databases ahead of the application fail closed.
