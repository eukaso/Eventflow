# EventFlow 1.2.0 — Sprint 11 UI Experience

- **Status:** Released
- **Release tag:** `v1.2.0-ui-experience`
- **Date:** 2026-08-20
- **Input release:** `v1.1.0-api-completion`

## Scope

EventFlow 1.2.0 adds secure, accessible WordPress browser experiences over the accepted EventFlow API. It provides an organizer operations workspace and a mobile-first guest RSVP journey without moving authorization, concurrency, idempotency, privacy, or business rules into client code.

## Included

- Event discovery, overview, lifecycle, setup, and Venue configuration;
- Membership, Invitation, and Attendee administration;
- fragment-bootstrapped guest Invitation and revision-safe RSVP;
- table, group, manual placement, readiness, and recommendation seating workflows;
- least-privilege event-day Reception and additive check-in reversal;
- Template, Campaign, audience-preview, Message, and retry administration;
- hardened Import, protected Export, Privacy, Audit, and sanitized diagnostic workflows;
- keyboard tab navigation, linked validation summaries, focus and high-contrast treatment;
- 320 CSS-pixel stacking, long-content resilience, and reduced-motion support;
- screen-scoped local WordPress assets and minimal runtime configuration.

## Compatibility

- Minimum PHP: 8.2
- Minimum WordPress: 6.5
- EventFlow schema: 15
- The release adds no schema migration.
- Admin and guest scripts are build-free and use browser/WordPress platform APIs only.
- Existing Sprint 3–10 baselines remain frozen and are not rewritten by this release.
