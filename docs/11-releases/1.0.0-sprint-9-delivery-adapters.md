# EventFlow 1.0.0 — Sprint 9 Delivery Adapters

- **Status:** Release Candidate
- **Candidate tag:** `v1.0.0-delivery-adapters`
- **Date:** 2026-08-18
- **Input release:** `v0.9.0-core-domain`

## Scope

EventFlow 1.0.0 adds a secure WordPress REST delivery boundary to the authoritative foundation and core-domain services released in 0.8.0 and 0.9.0. It intentionally exposes the supported command and query subset rather than fabricating transport behavior for catalogue operations without complete application contracts.

## Included

- normalized WordPress REST request, response, error, and request-ID handling;
- authenticated request contexts with idempotency and revision preconditions;
- Event, Membership, Invitation, Attendee, Seating, Check-In, Template, and Campaign command endpoints;
- rate-limited guest credential bootstrap and cookie-backed RSVP submission;
- least-privilege Reception search and privacy-minimized Campaign queue results;
- provider-authenticated raw webhook ingress with durable-before-ack processing;
- staged Import validation with closed column mappings and count-only results;
- full-mode-only product registration with minimal-mode health/readiness availability;
- executable IMP-028–IMP-042 evidence and a controlled deferred-route register.

## Compatibility

- Minimum PHP: 8.2
- Minimum WordPress: 6.5
- EventFlow schema: 6
- No database migration is introduced by Sprint 9.
- Ordinary HTTP bootstrap remains read-only and never executes migrations.
- Existing Sprint 3–8 baselines remain frozen and are not rewritten by this release.

## Controlled deferrals

The candidate does not claim full implementation of every route in the design catalogue. Query projections, lifecycle commands, upload/orchestration boundaries, and status services that lack authoritative contracts remain listed in `catalogues/EventFlow-Delivery-Deferred-Routes-v1.0.csv`.

The bundled Provider registry is empty until deployment supplies authenticated adapters. Live provider certification, WordPress/MySQL environment acceptance, and any admin or guest UI are outside this repository-local candidate gate.
