# EventFlow 0.9.0 — Sprint 8 Core Domain

- **Status:** Released
- **Release tag:** `v0.9.0-core-domain`
- **Date:** 2026-08-17
- **Input release:** `v0.8.0-foundation`

## Scope

EventFlow 0.9.0 adds the authoritative Event-scoped application services defined by the approved Sprint 6 design baseline and integrates them with the Sprint 7 persistence, transaction, authorization, idempotency, audit, job, error, health, and test foundation.

## Included

- Event lifecycle, readiness, venue snapshots, archive, and restore;
- membership management and primary-owner continuity;
- secure Invitations, guest links, sessions, and RSVP reconciliation;
- restart-safe imports and deterministic seating recommendations;
- least-privilege reception search, check-in, bulk operations, and reversals;
- immutable communications, Campaign audience freeze, and provider evidence processing;
- protected exports, privacy actions, retention holds, and restore reconciliation;
- structured observability, bounded metrics, and sanitized diagnostics;
- archived-Event mutation enforcement and provider outage circuit breaking;
- executable acceptance traceability for IV-001 through IV-020.

## Compatibility

- Minimum PHP: 8.2
- Minimum WordPress: 6.5
- EventFlow schema: 6
- Schema versions 5 and 6 are forward-only controlled extensions.
- Ordinary HTTP bootstrap remains read-only and never executes migrations.
- Existing Sprint 3–6 baselines remain frozen and are not rewritten by this release.
