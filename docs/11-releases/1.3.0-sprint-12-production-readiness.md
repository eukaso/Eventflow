## Scope

EventFlow 1.3.0 packages the production-readiness, deployment, provider, organizer-communication, and Lui @ 60 rollout work completed in Sprint 12. It adds deterministic release artifacts, backup-gated schema deployment, reference-data reconciliation, operational certification, Brevo/Twilio adapters, a one-screen communication workspace, a response dashboard, and a mobile personalized RSVP journey.

## Production cutover controls

This source release is not permission to send the full guest campaign. Production launch remains blocked until:

1. a fresh live database/files backup and rollback point are verified;
2. the production event is configured without the staging suffix or staging test record;
3. the authoritative guest list is reconciled after applying the one-companion rollout limit and approved family exceptions;
4. production Brevo/Twilio secrets, sender identity, callbacks, and bulk-delivery gate are verified outside Git;
5. one production email and one production SMS smoke test pass; and
6. the event owner gives explicit launch and bulk-send authorization.

The legacy plugin and its tables remain available throughout the rollback window.
