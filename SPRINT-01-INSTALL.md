# EventFlow Sprint 1 Final Documentation Package

Extract the `docs` folder over the root of your local EventFlow repository.

Then run:

```bash
git status
git add .
git commit -m "docs: finalize EventFlow documentation Sprint 1"
git push
git tag -a v0.2.1-docs-final -m "EventFlow Documentation Sprint 1 finalized"
git push origin v0.2.1-docs-final
```

This package promotes EF-DOC-000 and EF-DOC-001 to v1.0 approved baselines and adds EF-DOC-002, ADR-001 through ADR-012, EF-DOC-003, and Sprint 1 release notes.
